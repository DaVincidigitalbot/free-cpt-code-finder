Coding Decision Points

  • Use injury site, approach, and actual repair/resection work to choose CPT codes.
  • Do not let the trauma diagnosis substitute for operative detail.
  • Rib fixation add-on logic and staged reoperation modifiers require careful metadata review.

Common Documentation Gaps

Document injury mechanism only as context; CPT support comes from exploration, repair, resection, drainage, tube placement, fixation levels, and staged return details.

FAQ

What is CPT 20100?

CPT 20100 is exploration of a penetrating wound of the neck.

Does trauma surgery have one CPT family?

No. Trauma coding spans wound exploration, thoracic, abdominal, vascular, soft tissue, rib fixation, and critical care families.
