FAQ

How do I find the CPT code for a procedure?

Start with the exact procedure performed, then narrow by approach, site, laterality, complexity, time, and separately documented add-on work.

Can I bill a CPT code just because it is close to the procedure name?

No. Close is not enough. The note has to support the descriptor and the coding rules.

What should I search first?

Try the procedure name, the organ system, the common abbreviation, or the suspected CPT number.
