When to Use CPT 96366

CPT 96366 belongs behind a primary infusion administration code when documented infusion duration supports additional reportable time.

Documentation Checklist

  • Medication administered and clinical indication.
  • Route of administration: IV infusion versus IV push.
  • Start and stop time when infusion time drives the code.
  • Whether the code is initial, additional, or push administration.

Common Coding Traps

  • Billing 96366 without a primary infusion code.
  • Adding it for short extensions that do not meet payer time rules.
  • Failing to document total infusion duration.

Related Infusion Codes

96365 initial infusion, 96366 additional infusion hour, and 96374 IV push should be selected based on route and documented time. For the direct comparison, see 96365 vs 96374.

CPT 96366 FAQ

What is CPT 96366?

CPT 96366 reports each additional hour of therapeutic, prophylactic, or diagnostic IV infusion.

Is CPT 96366 an add-on code?

Yes. CPT 96366 is an add-on code and should be billed with a supported primary infusion administration code.

What is the work RVU for CPT 96366?

The work RVU for CPT 96366 is 0.18 in the Free CPT Code Finder database.
