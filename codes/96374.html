When to Use CPT 96374

CPT 96374 is the clean choice for an initial or single-substance IV push when documentation supports push administration rather than infusion time.

Documentation Checklist

  • Medication administered and clinical indication.
  • Route of administration: IV infusion versus IV push.
  • Start and stop time when infusion time drives the code.
  • Whether the code is initial, additional, or push administration.

Common Coding Traps

  • Calling a push an infusion.
  • Omitting route and medication details.
  • Billing multiple administration services without distinct documentation.

Related Infusion Codes

96365 initial infusion, 96366 additional infusion hour, and 96374 IV push should be selected based on route and documented time.

CPT 96374 FAQ

What is CPT 96374?

CPT 96374 reports a therapeutic, prophylactic, or diagnostic IV push for the initial or single substance/drug.

What is the work RVU for CPT 96374?

The work RVU for CPT 96374 is 0.18 in the Free CPT Code Finder database.

When should 96374 be used instead of 96365?

Use 96374 when the medication is given as an IV push rather than a documented time-based infusion.
