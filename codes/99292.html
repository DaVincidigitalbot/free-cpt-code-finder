Emergency Department Use Case

Critical care, each additional 30 min is represented in the ED procedures section because emergency physicians commonly bill this service during acute resuscitation, bedside procedures, and high-acuity encounters when documentation supports separate reporting.

Common Modifiers

None typically required

Related ICD-10 Coding Ideas

Billing Tips

Document timing, medical necessity, physician work personally performed, and any separately reportable procedures or imaging. If this is critical care, the time must be real and exclusive. If this is CPR, document arrest and active resuscitation. If this is intermediate laceration repair, document layered closure or contamination requiring the intermediate code family.

Documentation and Coding Notes

AdSense readiness coding note: CPT 99292 should be treated as an educational starting point, not a final billing instruction. For critical care, each additional 30 min, the operative note or procedure note should clearly support the approach, anatomic site, laterality when relevant, clinical indication, and any separately reportable services.

Before submitting a claim or logging the case, compare CPT 99292 with adjacent codes in the same family, confirm current AMA CPT language, check CMS/NCCI edits, and verify payer-specific bundling rules. Modifier use should be tied to documentation rather than added only to bypass an edit.

Common audit checks for emergency department procedures cases include whether the documented work matches the code descriptor, whether add-on services are separately supported, whether a global period applies, and whether ICD-10 diagnosis pairing supports medical necessity.
