Emergency Department Use Case

CPT 93308 is commonly searched by emergency physicians, trauma teams, residents, and coders when documenting a FAST ultrasound or other limited transthoracic echo in the ED. The chart should make the indication, technique, sedation status when relevant, imaging guidance when relevant, and immediate result easy to audit.

If this code was paired with critical care, fracture care, procedural sedation, ultrasound guidance, or a separately reportable evaluation and management service, make sure the documentation supports each distinct service.

Billing Tips

For ED billing, document medical necessity, consent when applicable, approach, laterality when relevant, fluoroscopy or ultrasound use when separately reportable, and whether manipulation or anesthesia was required. Weak procedure notes kill payment.

Documentation and Coding Notes

AdSense readiness coding note: CPT 93308 should be treated as an educational starting point, not a final billing instruction. For fast ultrasound / limited transthoracic echo, the operative note or procedure note should clearly support the approach, anatomic site, laterality when relevant, clinical indication, and any separately reportable services.

Before submitting a claim or logging the case, compare CPT 93308 with adjacent codes in the same family, confirm current AMA CPT language, check CMS/NCCI edits, and verify payer-specific bundling rules. Modifier use should be tied to documentation rather than added only to bypass an edit.

Common audit checks for emergency department procedures cases include whether the documented work matches the code descriptor, whether add-on services are separately supported, whether a global period applies, and whether ICD-10 diagnosis pairing supports medical necessity.
