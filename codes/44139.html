When This Add-On Is Reportable

Mobilization of the splenic flexure is separately reportable only when it is performed with an eligible partial colectomy. It should not be selected as an isolated CPT lookup result or primary Case Builder line.

Documentation should clearly state that the splenic flexure was mobilized/taken down and why: commonly to gain bowel length, reduce tension, or facilitate a tension-free anastomosis.

Approach Selection

  • 44139: Use with eligible open partial colectomy parent codes.
  • 44213: Use with eligible laparoscopic or robotic partial colectomy parent codes. Robotic colectomy is coded through the laparoscopic pathway.

Case Builder Guidance

The Case Builder surfaces splenic flexure mobilization as an educational add-on suggestion after an eligible colectomy is selected. It never auto-adds the add-on code.
