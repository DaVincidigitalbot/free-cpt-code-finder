When to Use CPT 96365

CPT 96365 is the first-hour infusion administration code. The key is documented infusion time, not just that an IV medication was given.

Documentation Checklist

  • Medication administered and clinical indication.
  • Route of administration: IV infusion versus IV push.
  • Start and stop time when infusion time drives the code.
  • Whether the code is initial, additional, or push administration.

Common Coding Traps

  • Missing start and stop times.
  • Using infusion coding for a rapid IV push.
  • Stacking additional hour codes without supported time.

Related Infusion Codes

96365 initial infusion, 96366 additional infusion hour, and 96374 IV push should be selected based on route and documented time.

CPT 96365 FAQ

What is CPT 96365?

CPT 96365 reports the initial therapeutic, prophylactic, or diagnostic IV infusion, up to 1 hour.

What is the work RVU for CPT 96365?

The work RVU for CPT 96365 is 0.21 in the Free CPT Code Finder database.

What documentation supports CPT 96365?

Document the medication, route, start time, stop time, and clinical indication.
