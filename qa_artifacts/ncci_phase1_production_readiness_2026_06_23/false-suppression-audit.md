# False Suppression Audit - 159-Pair Release Candidate

No true CMS-policy false suppression identified. The following are specific combinations that surgeons may commonly and legitimately document/report, but Medicare NCCI modifier-0 says the Column 2 code is not separately payable. These should stay in the release candidate, with explicit UX and post-deploy monitoring.
