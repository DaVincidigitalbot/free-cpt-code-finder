The Operative Note Library teaches documentation by contrast: weak examples, stronger examples, and the coding implications that follow.

Laparoscopic Cholecystectomy

Poor Documentation Example

"Laparoscopic Cholecystectomy performed. Patient tolerated procedure well."

This is weak because it does not explain indication, operative findings, critical steps, complexity, complications, specimens, implants, anatomic details, or whether separately reportable work was performed.

Strong Documentation Example

"After informed consent, the patient was taken to the operating room for laparoscopic cholecystectomy. The indication, key findings, approach, critical steps, and completion of the operation were documented. Relevant anatomy, complexity, and complications were addressed, and the patient left the operating room in stable condition."

Coding Implications

Coders and reviewers need the operative note to support the CPT family, approach, global period, modifier use, medical necessity, and whether additional services were actually distinct.
